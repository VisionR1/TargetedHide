## TargetedHide v2

* **Gallery & Media Hiding:** Photos, videos, and audio are now fully hidden from gallery apps, messaging apps (like WhatsApp/Telegram), and social media pickers.
* **No More Broken Thumbnails:** Intercepts Android's central media database (MediaStore) so hidden files no longer show up as gray boxes or lingering blank items.
* **Rock-Solid Stability:** Added advanced system protections to prevent silent background failures, guaranteeing your hidden media stays completely invisible.

## TargetedHide v1 — Initial Release

* **Selective Hiding:** Hide files, folders, or packages from specific target apps while all other apps remain completely unaffected.
* **True Invisibility:** Hidden items completely disappear from the target process as if they never existed.
* **Package Hiding:** Write a package name (e.g., `com.example.app`) to hide it completely from the target app.
* **Advanced Exclusions:** Use `!` to carve out exceptions, keeping specific files, subfolders, or packages visible inside hidden directories.
* **Global & Per-App Config:** Apply a global hide list, or create custom configs for specific apps.
