## TargetedHide v3

* **Faster Folder Loading:** Reduced lag and freezing when opening large folders, photo galleries, or music libraries.
* **Smooth App Performance:** Streamlined file handling to maintain responsiveness and reduce processing overhead.
* **Better Custom Software Support:** Fixed storage path issues on custom manufacturer software (like Xiaomi/MIUI) so files and folders recognize correctly.
* **Optimized Background Processing:** Prevented worker thread delays when apps handle multiple files at the same time.

## TargetedHide v2

* **Gallery & Media Hiding:** Photos, videos, and audio are now fully hidden from gallery apps, messaging apps (like WhatsApp/Telegram), and social media pickers.
* **No More Broken Thumbnails:** Intercepts Android's central media database (MediaStore) so hidden files no longer show up as gray boxes or lingering blank items.
* **Rock-Solid Stability:** Added advanced system protections to prevent silent background failures, guaranteeing your hidden media stays completely invisible.
